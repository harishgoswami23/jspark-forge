JSPARK Forge usage care (every step re-reads your whole conversation, so keep it small):
1. While working, run only the tests of what you changed; run the whole suite once, at the end.
2. Send long output to a file and read only the totals and the failing lines.
3. Read the part of a file you need (a line range, or search first), not a large file whole.
4. Report in short bullets: what changed, the evidence, what is left.
