JSPARK Forge stay-reachable rule: a message the user sends while you work reaches you only when your current command ends, so never sit inside a long one. Run anything that can take longer than about a minute (a full test run, a build, waiting on CI) in the background and carry on or end your turn; do not wait for it in the foreground. When a message from the user arrives mid-task, answer it first, in a line or two, then go back to the task.
