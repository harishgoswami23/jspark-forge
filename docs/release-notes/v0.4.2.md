# JSPARK Forge v0.4.2

*Claude Code forgets. JSPARK Forge doesn't, and now it keeps itself up to date.*

**Install** (superpowers comes with it; no setup step):

```
/plugin install jspark-forge --marketplace harishgoswami23/jspark-forge
```

Then turn on updates, once: type `/plugin`, open the **Marketplaces** tab, choose **jspark-forge** and turn on
auto-update. Already installed: do the same, then restart Claude Code. Needs Node.js 18 or newer.

## New

- **Updates without a command.** Claude Code updates plugins from Anthropic's own directory by itself, but from any
  other marketplace only when the user turns auto-update on, and a marketplace cannot switch it on for its users. So
  the install steps now include that one switch, and JSPARK Forge says once, in the first session, how to turn it on
  when it is off. It only reads Claude Code's list of marketplaces; it never changes it and never goes online.

## Fixed

- The version number is now set in one place (`plugin.json`), as Claude Code's documentation asks; it was also in
  the marketplace entry, where a mismatch on a future release could have held back an update.

## Tested

- 1,518 automated tests on Windows, macOS and Linux with Node 18, 22 and 24.
