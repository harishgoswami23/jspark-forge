# JSPARK Forge: next release (not released yet)

## Trust several build graphs in one message

- `TRUST GRAPH stage-1 stage-2 stage-3` trusts each graph you name, and the answer lists the commands of each.
- It is still only your own typed, whole message. Nothing is trusted that you did not name.
- All or nothing: if one name is missing, not valid, or its commands changed since they were shown, none is trusted.
  The answer says which one and why, and gives the exact text to send for the rest.
- A name given twice counts once. One that is already trusted is said to stand.
- Up to 12 names in one message.
