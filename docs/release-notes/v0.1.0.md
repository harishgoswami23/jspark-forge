# JSPARK Forge v0.1.0

*Claude Code forgets. JSPARK Forge doesn't.*

**Install** (superpowers comes with it; no setup step):

```
/plugin install jspark-forge --marketplace harishgoswami23/jspark-forge
```

On Claude Code older than 2.1.275: `/plugin marketplace add harishgoswami23/jspark-forge`, then `/plugin install jspark-forge`. Needs Node.js 18 or newer.

## What it does

- **Picks up where you left off.** A one-page handoff is saved after every file change, commit and reply, before compaction, at session end, and at 80 % and 95 % usage. Reopen Claude Code: *"last time you were on "Hello script", step 2 of 3. Next: Add a test."* Claude then asks "Continue?" and waits.
- **Blocks 9 dangerous actions** with hooks: wiping work, force-pushing main, destructive SQL, editing secret files and more. Type `CONFIRM <name>` to allow one once. `rm -rf` on your home folder, the root or a drive is always refused.
- **Keeps Claude grounded:** cite the file and line, or say "not found".
- **Comes with superpowers** (by Jesse Vincent, MIT) for planning, test-first coding and reviews; the handoff shows its plan progress.

## Tested

- 332 tests on Windows, macOS and Linux with Node 18, 22 and 24.
- The ship gate on Windows: Claude Code killed mid-task on a 68,000-line project; a new session showed where we were in 7.7–8.6 seconds, with nothing changed.

## Known limits

- PowerShell command forms are blocked from v0.1.1; v0.1 matches Bash / Git Bash forms.
- A seatbelt, not a sandbox: a deliberately disguised command can get through.
- The full ship gate on macOS and Linux is still pending.
- If you already had superpowers from another marketplace, it is installed twice; JSPARK Forge says once which copy to remove.
