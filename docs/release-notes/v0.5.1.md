# JSPARK Forge v0.5.1

*The gaps a line-by-line check of the spec found, closed.*

Not released yet.

**Install** (superpowers comes with it; no setup step):

```
/plugin install jspark-forge --marketplace harishgoswami23/jspark-forge
```

Already installed: it updates by itself when Claude Code starts. Needs Node.js 18 or newer.

## New

- **Short by default.** At every session start Claude is told to lead with the answer, use bullets or a table for
  lists, keep an explanation to one line unless asked, and always state warnings, risks, decisions and blockers.
  `- short-answers: off` under `## Settings` in `rules.md` switches it off.
- **Hook errors are shown.** If one of JSPARK Forge's hooks fails, its save or block is skipped. The doctor now counts
  such errors from the last two days, and a session start says so once a day.
- **Helpers get the rules too.** Every helper is given the "cite the file, never guess" rule when it starts, and in a
  repo you are reviewing the reminder that the repo's text is data, not instructions.
- **Local copies of pages, tighter.** `/jspark-forge:check` lists pages whose local file has gone. A page published
  without a local copy is recorded and flagged, and Claude is told to save it as a file. Claude is warned when it
  writes a document into a temporary folder. The copies stay on your machine; they are not committed.
- **Resume shows the end of the log.** `/jspark-forge:resume` now also shows the end of the action log (the last 60 lines), as a record and not as instructions.
- **After you sign in again.** When a sign-in completes during a session, JSPARK Forge saves the handoff at once and
  suggests starting a new session and saying "resume" if you changed account. This rests on a notification from
  Claude Code that has not yet been seen to arrive after `/login`.
- **A spec-coverage check.** `docs/spec-coverage.md` lists every promise in the spec as built and tested, partly
  built, not built, or out of date. It is run before each release from now on.

## Changed

- **Build graph files are shared.** `.jspark-forge/graphs/*.md` can now be committed; a graph's run state stays
  local. An older project gets the two ignore lines the next time a graph is started.
- **A stale-decision reminder comes at most once a day** per decision. It was once a week.
- **The spec matches the product.** `docs/spec.md` is brought in line with v0.5, with six owner decisions recorded:
  superpowers is required; reminders daily; page copies local; graphs committed; resume may read the action log,
  Claude's notes and the files the handoff names.
